# 🌸 Iris Flower Classifier

Classic ML classifier on the famous Iris dataset.

## 📊 Model Details

- **Dataset:** Iris (150 samples, 4 features, 3 classes)
- **Algorithm:** Logistic Regression
- **Test accuracy:** ~97%
- **Training time:** < 1 second

## 🎯 What It Does

Given 4 measurements of an iris flower, predicts which species it is:
- Sepal length (cm)
- Sepal width (cm)
- Petal length (cm)
- Petal width (cm)

**Classes:**
- Setosa
- Versicolor
- Virginica

# 🔢 MNIST Digit Classifier

CNN classifier for handwritten digits (0-9) on MNIST dataset.

## 📊 Model Details

- **Architecture:** Small CNN (2 conv layers)
- **Dataset:** MNIST (60,000 train + 10,000 test)
- **Training:** 5 epochs
- **Test accuracy:** ~99%
- **Parameters:** ~120,000
